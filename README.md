⚓ Batalha Naval - Simulação em C

Eu criei esse projeto de Batalha Naval enquanto estudava Ciência da Computação. Queria ver na prática como funcionam os conceitos básicos de programação estruturada e lógica computacional.

🚀 Sobre o Projeto
O jogo roda no console e você interage com ele digitando comandos. Você pode colocar suas frotas no tabuleiro e fazer ataques estratégicos. O tabuleiro é como um quadro com linhas e colunas.

🛠️ Como foi feito

*   Linguagem C: foi a linguagem que usei para criar o jogo.

*   Matrizes: usei para mostrar o oceano e onde estão os navios.

*   Loops (for e while): usei para mostrar o tabuleiro e controlar as rodadas.

*   Condicionais: usei para checar se as coordenadas são válidas e saber se você acertou ou não.

  ⚓ Battleship – C Programming Simulation
I built this Battleship project while studying Computer Science to get some hands-on experience with structured programming and computational logic.

🚀 Project Overview
The game runs directly in the console, where you interact with it through terminal commands. You can position your fleet on the board and execute strategic strikes. The board itself is managed through a grid system of rows and columns.

🛠️ Technical Breakdown

C Language: The core language used to build the entire game.

Matrices (2D Arrays): Used to render the ocean grid and track ship placements.

Loops (for & while): Used to refresh the board display and manage the turn-based system.

Conditionals: Implemented to validate coordinates and determine hits or misses.
